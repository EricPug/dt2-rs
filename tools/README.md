- `run-section3.sh`: runs the section-3 boot scenario with a given `dt2-cli` binary and instruction limit.
- `probe-from-snapshot.sh`: restores a machine snapshot (`SNAP`, default `out/idle2.snap`) and runs an experiment with extra flags.
- `build-opcode-probe.sh`: builds a scratch `dt2-cli` that dumps distinct executed opcode words (`OPCODE_DUMP=path`) plus the `decode_probe` helper.
- `opcode_probe_patch.py`: the source patch `build-opcode-probe.sh` applies to the scratch copy.
- `decode_probe.rs`: example that steps one instruction from hex bytes and prints accept/length/reject.
- `opcode-diff.py`: compares the emulator's decode of executed opcodes with Capstone; ColdFire-only MVS/MVZ/FF1 are expected differences.
- `render-uploads.py`: renders distinct display-upload buffers (`DUMP_CALL` output) as 4bpp and 8bpp PNGs and counts distinct frames.
- `render-uart-frames.py`: replays one or more sequential UART8 TX byte dumps (`UART8_TX_FILE`) into a shared 64x128 framebuffer; prints per-input changed-pixel counts and saves each input's final frame, sampled frames, and a montage. Example: `python3 tools/render-uart-frames.py out/repeat-a-uart.bin out/continuation-1b-plus-200m-uart.bin out/replay-1p2b`.
- `ui-smoke.sh`: verifies the deterministic boot-to-SAMPLE-page, encoder, and page-change screenshots.
- `audio-edma-trace.sh`: records sample-load and trigger/play eDMA requests; `EDMA_TRACE` prints each firmware SERQ request with its TCD fields. It watches DSPI1 request construction and the response buffer's CPU reads/writes. The trace uses placeholder DSPI2 replies and is not audio playback evidence.
- `dt2-cli` flags `LIVE_WINDOW[=scale]` (feature `window`) and `LIVE_PNG=path`: live or headless upright display of the UART8 tile stream; see the handoff doc.
- `check-1b-baseline.sh <binary> <label>`: 1B-instruction boot with the in-memory synthetic eMMC; prints the saved snapshot SHA-256 (acceptance check for performance changes).
- `scan-panel-input.sh <binary> <snapshot> "<first bytes>" "<values>"`: injects each two-byte panel message from a display snapshot and reports TX traffic and whether the frame changed (finds messages the UI responds to).
